# ⚡ Core Features

**Dual NFT Support**\


RAXUS offers support for both:

&#x20;• Fungible NFTs (f-NFTs): Fractionalized ownership of real-world assets (e.g., real estate, luxury goods, art collections).

&#x20;• Non-Fungible NFTs (NFTs): Unique, one-of-one digital or physical art, collectibles, and identity-bound tokens.
